# 1xOps Command Center

Persistent terminal sessions, processes and text-file tools for Claude Code, Claude Desktop and OpenAI Codex, limited to the folders a person allows. Runs locally on macOS, Linux and Windows. Sends nothing anywhere.

```
/plugin marketplace add 1xOps/command-center
/plugin install command-center@command-center
```

| Folder | What it is |
|---|---|
| [`mcp-server/`](mcp-server/README.md) | the npm package `@1xops/command-center`: server, tests, Claude Desktop bundle, container image |
| [`plugins/command-center/`](plugins/command-center/README.md) | the Claude Code plugin: the pinned server plus six skills |
| [`docs/supply-chain/register.md`](docs/supply-chain/register.md) | every shipped package and its licence, signed by the owner |
